# Kage — temple landing page

The packaged Kage page from the MIT-licensed `@designcodeio/threeui` npm package
(v1.2.0), copied byte-for-byte. `index.html` is `kage.html` unchanged
(SHA-256 c8e06b90397ac246baf0ab6f32f5f6b570acc6fe03c7009f711b579fb72d9f49).
Fonts, Three.js and all images are local, so it needs no build and no network.

## Deploy to Vercel (free Hobby plan)

1. Upload this folder's contents to a new GitHub repository (index.html and the
   `secret-pathways-assets` folder must sit at the repo root).
2. Go to https://vercel.com/new, import the repository, keep the defaults
   (Framework Preset: Other, no build command) and click Deploy.

Or from a terminal: `npm i -g vercel && cd kage-site && vercel --prod`
